catHopia is a 2D pixel-art game concept built for players of all ages: choose one of five cats, choose a world to run through, and survive as long as possible without hitting an obstacle. The whole loop rests on a single input — jump — so the only real decision is when.

## What I did

- Designed the game's core concept, mechanics, and overall gameplay loop as lead game designer
- Planned milestones, organized tasks, and kept the project on schedule as project manager
- Facilitated collaboration and kept communication clear across the team

## What I learned

Running a small team taught me as much as designing the concept of the game did. The mechanics stayed simple on purpose — one button, one goal — so most of the real design work went into the moments around the run: a character worth picking, a world worth noticing, a game over screen that makes you want to hit continue.
