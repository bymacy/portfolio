A weekend experiment that turned into a study of variable fonts. Scroll velocity drives weight and width, so the page feels like it has inertia.

## What I did

- Mapped scroll velocity to a variable font's weight and width axes
- Added a rest state so the type settles rather than snapping back
- Tested nine typefaces and kept the three that survived fast scrolling
- Wrote up the performance notes — the naive version dropped to 24fps

## What I learned

Motion tied to input velocity needs damping or it reads as broken. The fix was a spring on the axis values, not a faster render loop.
